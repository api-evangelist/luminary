# Luminary

> Luminary is AI-powered estate planning software for wealth advisors, family offices, attorneys, and professional services firms. Its public REST API (v1) exposes households, individuals, entities, documents, AI document summaries, and entity valuations so estate planning data can sync with CRMs, client portals, and planning tools. Backed by 8vc.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public OpenAPI and developer surface; it is not published by Luminary.

## API
- [Luminary API OpenAPI (v1.0.0)](openapi/luminary-openapi-original.yml): 31 operations over households, individuals, entities, documents, document-summaries, valuations, users. Base URL https://{subdomain}.withluminary.com/api/public/v1
- [Authentication](authentication/luminary-authentication.yml): OAuth2 (authorizationCode + clientCredentials), issuer https://auth.withluminary.com, PKCE S256
- [OAuth scopes](scopes/luminary-scopes.yml): openid, profile, email, offline_access
- [Conventions](conventions/luminary-conventions.yml): cursor pagination, prefixed-ULID ids, external_id correlation, custom error envelope
- [Error catalog](errors/luminary-problem-types.yml): custom {code, message, details[]} envelope
- [Data model](data-model/luminary-data-model.yml): Household -> Individual/Entity/Document; Entity -> Valuation -> Asset
